DEVKIT AI — Kaggle + Ollama + Cloudflare Tunnel

Hướng dẫn chạy một model Ollama trên GPU tạm thời của Kaggle và kết nối model đó với VS Code thông qua Cloudflare Tunnel.

Trước khi bắt đầu

  • Tạo hoặc đăng nhập tài khoản Kaggle và hoàn tất xác minh số điện thoại nếu được yêu cầu.
  • Chọn Create → New Notebook.
  • Trong phần cài đặt Notebook bên phải, bật Internet.
  • Đặt Accelerator thành GPU.
  • Trong Kaggle, bấm + Code để thêm một cell.
  • Các lệnh bắt đầu bằng ! là shell command; các Python cell không dùng !.
  • Sử dụng chính xác tên model qwen3.8:latest trong toàn bộ quá trình thiết lập.

1. Kiểm tra GPU

Sau khi chọn GPU trong phần cài đặt Kaggle, chạy:

!nvidia-smi

Nếu bạn thấy thông tin về GPU NVIDIA thì GPU đã được kích hoạt.

2. Cài đặt Zstandard

Trình cài đặt Ollama có thể cần zstd để giải nén file tải xuống.

!sudo apt-get update -y
!sudo apt-get install -y zstd

3. Cài đặt Ollama

!curl -fsSL https://ollama.com/install.sh | sh

4. Xác nhận Ollama đã được cài đặt

!ollama --version

Bạn sẽ thấy số phiên bản của Ollama.

5. Khởi động Ollama Server

Chạy đoạn code này trong một Python code cell:

import subprocess
import time
ollama_process = subprocess.Popen(
    ["ollama", "serve"],
    stdout=subprocess.DEVNULL,
    stderr=subprocess.DEVNULL
)

time.sleep(5)
print("Ollama started")

6. Xác nhận Ollama đang chạy

!curl http://127.0.0.1:11434

Kết quả mong đợi:

Ollama is running

7. Tải model AI

!ollama pull qwen3.8:latest

Chờ quá trình tải hoàn tất hoàn toàn.

8. Kiểm tra tên model đã cài

!ollama list

Bạn sẽ thấy:

qwen3.8:latest

Hãy sử dụng chính xác tên này trong tất cả các lệnh tiếp theo và trong VS Code.

9. Kiểm tra model cục bộ

Chạy trong một Python code cell:

import requests
response = requests.post(
    "http://127.0.0.1:11434/api/generate",
    json={
        "model": "qwen3.8:latest",
        "prompt": "Reply with exactly: DEVKIT AI model test successful.",
        "stream": False
    },
    timeout=300
)

print("Status:", response.status_code)
print(response.text)

Nếu thành công, kết quả sẽ hiển thị:

Status: 200
DEVKIT AI model test successful.

10. Cài đặt Cloudflared

!wget -q https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb
!sudo dpkg -i cloudflared-linux-amd64.deb

11. Xác nhận Cloudflared đã được cài đặt

!cloudflared --version

Bạn sẽ thấy số phiên bản của Cloudflared.

12. Tạo Cloudflare Tunnel

Chạy đoạn code này trong một Python code cell:

import subprocess
import time

cloudflared = subprocess.Popen(
    [
        "cloudflared",
        "tunnel",
        "--url", "http://127.0.0.1:11434",
        "--http-host-header", "localhost:11434"
    ],
    stdout=subprocess.PIPE,
    stderr=subprocess.STDOUT,
    text=True
)

time.sleep(8)
for _ in range(30):
    line = cloudflared.stdout.readline()
    if line:
        print(line, end="")

Chờ xuất hiện một URL tạm thời tương tự:

https://something-random.trycloudflare.com

Hãy copy URL đó.

Quan trọng: Hãy giữ cell này tiếp tục chạy. Nếu bạn dừng cell, public tunnel cũng sẽ ngừng hoạt động.

13. Kiểm tra Public Tunnel

Thay URL mẫu bằng URL tunnel thực tế của bạn:

import requests
PUBLIC_URL = "https://your-tunnel.trycloudflare.com"
response = requests.get(PUBLIC_URL + "/api/tags", timeout=60)
print("Status:", response.status_code)
print(response.text)

Nếu bạn nhận được status 200 cùng danh sách model thì tunnel đang hoạt động.

14. Cấu hình Cline trong VS Code

Mở VS Code → mở/cài đặt Cline → chọn OpenAI Compatible làm API Provider.

Nhập các thông tin sau:

Thiết lậpGiá trị
API ProviderOpenAI Compatible
Base URLhttps://your-tunnel.trycloudflare.com/v1
API Keyollama
Model IDqwen3.8:latest

Thay your-tunnel.trycloudflare.com bằng Cloudflare URL hiện tại của bạn.

Quan trọng: Base URL bắt buộc phải kết thúc bằng /v1.

15. Prompt kiểm tra Cline lần đầu

Gửi prompt sau:

Reply in one short sentence: confirm that you are connected and ready.

Xử lý sự cố

Không nhìn thấy GPU

  • Vào phần cài đặt Kaggle Notebook.
  • Kiểm tra Accelerator đã được đặt thành GPU.
  • Chạy lại:
!nvidia-smi

Ollama không chạy

Chạy lại Python cell khởi động server, chờ vài giây rồi chạy:

!curl http://127.0.0.1:11434

Không tìm thấy model

Chạy:

!ollama list

Copy chính xác tên model. Trong hướng dẫn này là:

qwen3.8:latest

Tunnel không hoạt động

  • Đảm bảo Cloudflare tunnel cell vẫn đang chạy.
  • Đảm bảo phiên Kaggle chưa bị dừng.
  • Copy đầy đủ URL bắt đầu bằng https://.

VS Code/Cline không thể kết nối

Kiểm tra:

  • Base URL kết thúc bằng /v1.
  • API key là ollama.
  • Model ID là qwen3.8:latest.
  • Cloudflare tunnel vẫn đang chạy.

Dọn dẹp sau khi sử dụng

Khi hoàn tất:

  1. Dừng Cloudflare tunnel cell.
  2. Dừng phiên Kaggle Notebook.
  3. Xóa temporary endpoint khỏi Cline nếu bạn không còn cần sử dụng.
GPU của Kaggle phụ thuộc vào quota. Cloudflare Quick Tunnels được thiết kế cho mục đích kiểm thử/phát triển tạm thời, không phải để hosting lâu dài.
