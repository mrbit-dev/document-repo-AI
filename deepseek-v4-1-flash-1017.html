Các Đột Phá Kiến Trúc Của Bản Cập Nhật 1017

DeepSeek tiếp tục nâng tầm dòng mô hình Flash với việc tích hợp Engram Memory và thuật toán nén KV Cache tiên tiến nhất hiện nay.

⚡

Causal Encoder-Decoder (CED) & MoE Định Tuyến 6/384

Sở hữu 40 Transformer layers chia đều giữa Encoder và Decoder. Cơ chế định tuyến chỉ kích hoạt 6 trong 384 chuyên gia (experts) cho mỗi token cùng 1 shared expert. Nhờ đó, model sở hữu dung lượng kiến thức khổng lồ của 763B tham số nhưng độ trễ và chi phí suy luận chỉ tương đương model 8B–16B.

6/384 Active Experts 8B Prefill Active 16B Generation Active
🧠

Engram Memory 196B Tích Hợp Sẵn

Trang bị hệ tầng Engram Memory cố định 196 tỷ tham số như một kho dữ liệu tri thức tĩnh (code syntax, thư viện, tài liệu toán học, kernel OS). Khi truy xuất thông tin nền tảng, model không cần kích hoạt lại các nơ-ron suy luận phức tạp, giúp tăng tốc độ phản xạ.

196B Engram Memory Bộ Nhớ Cố Định Tối Ưu BF16 / FP8 Tensor
📉

Nén KV-Cache Kỷ Lục: 890 Bytes/Token

Nhờ Compressed Sparse Attention 2 (CSA2) và kỹ thuật Bounded Replay hỗ trợ định dạng FP4 Main KV Caching. Mức tiêu hao RAM giảm hơn 65% so với các model cùng phân khúc, cho phép phục vụ cửa sổ ngữ cảnh 1 triệu token (1M tokens) với chi phí phần cứng siêu rẻ.

import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "YOUR_FREE_DEVKIT_API_KEY",
  baseURL: "https://api.deepseek.com/v1"
});

async function runDeepSeek() {
  const stream = await client.chat.completions.create({
    model: "deepseek-ai/DeepSeek-V4.1-Flash-1017",
    messages: [
      { role: "system", content: "Chuyên viên kiến trúc phần mềm AI DEVKIT." },
      { role: "user", content: "Viết Agentic Tool Call với mô hình DeepSeek 1017." }
    ],
    temperature: 1.0,
    stream: true,
  });

  for await (const chunk of stream) {
    process.stdout.write(chunk.choices[0]?.delta?.content || "");
  }
}

runDeepSeek();
