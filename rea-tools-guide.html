REA: Trao Quyền "Dịch Ngược Phần Mềm" Cho AI Coding Agent

REA (viết tắt của Reverse Engineer Anything — tác giả Moe Lueker / morluto, trang chủ rea.tools) là bộ công cụ mã nguồn mở và máy chủ Model Context Protocol (MCP) đột phá. Nó đóng vai trò cầu nối trung gian giữa các phần mềm dịch ngược chuyên sâu (Ghidra, Hopper, IDA, JADX, AST parsers) và các AI coding agents (Claude Code, Cursor, Codex, Windsurf, Gemini CLI), cho phép AI mổ xẻ, hiểu và tái tạo mã nguồn từ ứng dụng đóng mà không cần có source code ban đầu.

1. Vấn Đề Lớn: Rào Cản Dịch Ngược Cổ Điển & Hạn Chế Của LLM

Khi bạn cần tìm hiểu một ứng dụng Electron, một file binary .exe, một thư viện .dll, hay một API bí mật của website đối thủ... bạn thường đối mặt với hai bức tường lớn:

Khi Tự Làm Thủ Công Hoặc Dùng LLM Thuần Túy
  • ❌ Đòi hỏi chuyên môn siêu khó: Bạn phải học assembly x86/ARM, nắm vững Ghidra, IDA Pro, r2, mổ xẻ hex dump mất hàng tuần trời.
  • ❌ LLM bị "ảo giác" (Hallucination): Khi ném file mã máy hoặc minified code vào ChatGPT/Claude, mô hình tự bịa ra logic dựa trên phỏng đoán thiếu căn cứ.
  • ❌ Tràn Context Window: Các file binary đã decompile hay assembly dump chứa hàng triệu dòng dữ liệu thô, làm tê liệt cửa sổ ngữ cảnh của AI.
  • ❌ Nguy cơ bảo mật: Upload file thực thi nội bộ hoặc mã nhạy cảm lên các dịch vụ đám mây công cộng.
Khi Sử Dụng REA + AI Coding Agent
  • ✅ Agent tự động điều khiển công cụ dịch ngược: AI tự gọi REA để quét static AST, decompile hàm mục tiêu, trích xuất chuỗi và xrefs.
  • ✅ Dựa trên bằng chứng xác thực (Evidence-based): REA trả về các chứng cứ kỹ thuật cụ thể (call graphs, strings, IPC channels) nên AI không bao giờ bịa đặt.
  • ✅ Tối ưu hóa token (Compact Profiles): Cơ chế schema rút gọn chỉ nạp dữ liệu liên quan đến hàm cần phân tích, bảo tồn context window.
  • ✅ 100% Cục bộ (Local Sandbox): Toàn bộ quá trình giải mã chạy hoàn toàn trên máy tính cá nhân của bạn.

2. Triết Lý Cốt Lõi: Mô Hình Tư Duy 3 Giai Đoạn

REA được xây dựng dựa trên chu trình làm việc 3 bước khép kín giúp biến phần mềm đã đóng gói thành code hiện đại:

1

Decompile (Giải Mã)

Mở các file ứng dụng mục tiêu (binary C/C++, gói Electron .asar, file .apk Android, assembly .dll hoặc frontend web) để trích xuất cấu trúc thư mục, bảng symbol, chuỗi text, các hàm và IPC channels khả đọc.

2

Understand (Thấu Hiểu)

Agent sử dụng REA MCP để lần theo dấu vết (Trace) đường đi của dữ liệu: "Hàm này nhận đầu vào từ đâu? Mã hóa bằng thuật toán gì? Gọi qua endpoint nào?". Mọi kết luận đều đi kèm bằng chứng mã nguồn rõ ràng.

3

Recreate (Tái Tạo)

Sau khi đã hiểu rõ logic thực thi, AI Coding Agent chuyển thể chính xác thuật toán đó sang ngôn ngữ và kiến trúc hiện tại của dự án bạn (ví dụ: viết lại thuật toán mã hóa C++ thành TypeScript cho NestJS).

💎

🚀

Xóa Bỏ Rào Cản Kỹ Thuật

🔌

Chuẩn Giao Thức MCP

Tích hợp mượt mà vào Claude Code, Cursor, Codex, Windsurf, Gemini CLI... Tự động thêm prompt workflow và tool schemas chỉ với 1 lệnh setup.

Hỗ Trợ Đa Mục Tiêu Phong Phú

Xử lý từ ứng dụng Desktop Electron, native binaries (Mach-O, ELF, PE), file thư viện .NET, file nén APK Android đến Web SPA và WebAssembly.

🧩

Tương Thích Mọi Disassembler

Tận dụng sức mạnh sẵn có của các engine dịch ngược nổi tiếng như Ghidra (NSA), Hopper, IDA Pro hoặc chạy parser AST tĩnh hoàn toàn tự động.

🛡

Quyền Riêng Tư Tuyệt Đối

Tất cả quá trình bóc tách mã nguồn thực hiện 100% cục bộ trên máy trạm của bạn. Không có file binary nhạy cảm nào bị gửi lên cloud.

⏱

Rút Ngắn Thời Gian Nghiên Cứu

Rút ngắn quy trình tìm kiếm API ngầm, kiểm thử tương thích (interoperability), phân tích giao thức mạng từ nhiều tuần xuống chỉ còn vài phút.

4. Các Mục Tiêu & Định Dạng REA Hỗ Trợ Phân Tích

Định dạng / Mục tiêu Công nghệ nền tảng Khả năng phân tích của REA
JavaScript & Electron Apps Gói .asar, Webpack / Vite bundles, Minified JS Giải nén tự động, phân tích AST tĩnh, bóc tách API ngầm, IPC channels, trích xuất cấu trúc source maps.
Native Binaries C/C++, Rust, Go, Swift (PE .exe, ELF, Mach-O) Kết nối với Ghidra, Hopper, IDA Pro để lấy symbol tables, pseudocode, danh sách x-refs, hàm xuất khẩu.

Mobile Apps (Android) File .apk, .aab, DEX, Resources Trích xuất manifest, assets, kết nối JADX để dịch ngược bytecode Java/Kotlin sang mã nguồn dễ đọc.
Websites & Web Apps Frontend SPAs, WebSocket, XHR APIs Truy vết thuật toán tạo chữ ký bảo vệ (HMAC, signature headers), giải mã state machines và endpoints nội bộ.
Firmware & WebAssembly WASM Bytecode, SQLite databases, IoT images Phân tích cấu trúc bảng dữ liệu, hàm export/import WASM, mổ xẻ cấu trúc phân vùng binary.

5. Hướng Dẫn Cài Đặt Chi Tiết

Yêu cầu hệ điều hành & môi trường:

  • Đã cài đặt Node.js phiên bản 20+ hoặc 22+: Kiểm tra bằng node -v.
  • Hỗ trợ hoàn hảo: macOS, Linux, Windows.
  • Đã có sẵn ít nhất một AI Coding Agent (Claude Code, Cursor, Codex, Windsurf, v.v.).

Đây là phương thức nhanh và chính xác nhất. REA sẽ quét toàn bộ các AI Agent đang có trên máy bạn, hỏi bạn muốn tích hợp vào đâu và tự động cấu hình file setting:

Terminal (bash / zsh / powershell) 
npx rea-agents@latest setup
💡
Điều gì sẽ xảy ra? Wizard tương tác sẽ nhận diện Claude Code, Cursor, Windsurf... tạo bản sao lưu (backup) cấu hình cũ của bạn, sau đó chèn cấu hình máy chủ MCP rea cùng các chỉ dẫn quy trình (rules/skills) tương ứng.

Cài đặt gói rea-agents dưới dạng công cụ dòng lệnh toàn cục để có thể gọi trực tiếp lệnh rea từ bất kỳ thư mục nào:

Terminal 
npm install --global rea-agents

Sau khi cài, bạn có thể chạy rea --help để xem toàn bộ danh mục tính năng.

Chạy chẩn đoán môi trường để kiểm tra xem hệ thống đã có các công cụ dịch ngược (Ghidra, Hopper, JADX) hoặc thiếu dependencies nào không:

Chạy kiểm tra môi trường 
npx rea-agents doctor
🤖

6. Cấu Hình Chi Tiết Cho Từng AI Coding Agent

Với Claude Code, sau khi chạy npx rea-agents@latest setup, REA sẽ tự động thêm cấu hình máy chủ MCP vào ~/.claude.json hoặc file cấu hình MCP của bạn:

Mẫu cấu hình MCP thủ công trong Claude Code settings 
{
  "mcpServers": {
    "rea": {
      "command": "npx",
      "args": ["-y", "rea-agents@latest", "mcp"],
      "env": {
        "RE_MCP_OUTPUT_SCHEMA_PROFILE": "compact"
      }
    }
  }
}
🎯
Biến môi trường RE_MCP_OUTPUT_SCHEMA_PROFILE=compact: Giúp rút gọn định dạng output schemas, tiết kiệm token tối đa cho Claude Code mà vẫn giữ nguyên tính chính xác của các công cụ.

Trong Cursor, vào Settings ➔ Features ➔ MCP Servers ➔ Bấm Add new MCP Server:

  • Name: rea
  • Type: command
  • Command: npx -y rea-agents@latest mcp

Hoặc thêm trực tiếp vào file .cursor/mcp.json trong dự án của bạn.

Cho bất kỳ Agent nào hỗ trợ chuẩn MCP (như Windsurf, Codex CLI, Antigravity):

Cấu hình chuẩn MCP JSON 
{
  "mcpServers": {
    "rea": {
      "command": "npx",
      "args": ["-y", "rea-agents@latest", "mcp"]
    }
  }
}

7. Bộ Lệnh CLI & Danh Mục MCP Tools Quyền Năng

1. Các lệnh CLI dùng độc lập ngoài Terminal

Bạn có thể tự chạy các lệnh phân tích trước khi nhờ AI xử lý:

Phân tích ứng dụng JavaScript / Electron 
# Phân tích tĩnh gói app Electron trích xuất
npx rea-agents analyze-javascript-application /duong/dan/app --json

# Quét và phân tích tổng quan
rea analyze ./Slack.app

# Tìm kiếm chuỗi ký tự hoặc API bí mật trong app
rea search ./target-app "api.internal.domain"

# Theo dõi luồng xử lý tính năng
rea trace ./target-app "auth_token_generator"

2. Các Tools mà REA cung cấp cho AI Coding Agent qua MCP

🛠 analyze_target

Nhận diện định dạng mục tiêu (PE, ELF, Mach-O, ASAR, APK), trích xuất metadata tổng quan, các dependencies và điểm khởi đầu (entry points).

🔍 search_symbols_and_strings

Tìm kiếm các chuỗi văn bản cứng (hardcoded strings), URLs, API keys ngầm, tên hàm và symbol tables bên trong tệp nhị phân.

🧩 decompile_function

Điều khiển decompiler địa phương (Ghidra/Hopper/AST) để chuyển đổi một hàm nhị phân cụ thể sang mã giả C hoặc AST dễ đọc.

🌐 trace_feature_flow

Truy vết đồ thị gọi hàm (call graph) và mối quan hệ chéo (cross-references) liên quan trực tiếp đến một tính năng được yêu cầu.

⚡ extract_ipc_channels

Đặc trị cho ứng dụng Electron: Quét toàn bộ kênh liên lạc giữa tiến trình Main và Renderer để tìm các hàm ngầm không công khai.

📦 extract_assets_and_routes

Trích xuất cấu trúc thư mục, routes API, giao diện và file cấu hình bị đóng gói trong file nhị phân hoặc archive.

💡

8. Hướng Dẫn Sử Dụng Thực Chiến & Kịch Bản Mẫu

Khi đã tích hợp REA vào Claude Code hoặc Cursor, bạn chỉ việc trò chuyện tự nhiên. Hãy xem 3 kịch bản thực tế phổ biến nhất:

Kịch Bản 1: Tìm API Ngầm & Thuật Toán Tạo Header Ký Của Ứng Dụng Electron Electron App

Bạn muốn tích hợp với một ứng dụng desktop nhưng họ không cung cấp Public API.

Prompt mẫu gửi cho Claude Code / Cursor 
Hãy dùng REA phân tích file `app.asar` của ứng dụng tại đường dẫn `./dist/resources/app.asar`.
1. Tìm tất cả các endpoint API gửi lên domain `api.example.com`.
2. Kiểm tra xem header `X-App-Signature` được tạo ra bằng thuật toán nào (tìm HMAC hay secret key nếu có).
3. Viết lại hàm tạo request đó bằng TypeScript và Axios cho dự án của tôi.
🎯
Hành động của AI: Agent tự gọi rea.extract_ipc_channels và phân tích AST trong file app.asar, định vị chính xác file bundle chứa logic ký mã, trích xuất chuỗi salt bí mật và viết ngay hàm TypeScript hoàn chỉnh cho bạn!
Kịch Bản 2: Tái Tạo Thuật Toán Nén / Tính Toán Từ Thư Viện C++ Binary (.dll / .so) Native Binary

Bạn có một file binary cũ từ nhà cung cấp nhưng đã mất mã nguồn gốc.

Prompt mẫu gửi cho AI Agent 
Dùng REA kiểm tra file thư viện `libcalculator.so`.
1. Tìm hàm xuất khẩu `compute_custom_checksum`.
2. Dịch ngược mã giả (pseudocode) của thuật toán này.
3. Giải thích logic thuật toán và chuyển thể mã đó sang ngôn ngữ Python 3.
Kịch Bản 3: Kiểm Tra An Toàn Bảo Mật & Phát Hiện Lộ Lọt Secret Trong File APK Mobile Security

Đánh giá xem app di động Android của công ty có vô tình bị lộ API keys quan trọng không.

Prompt mẫu 
Hãy dùng REA quét toàn bộ file `mobile-app.apk`.
Tìm tất cả các API keys, AWS tokens, chuỗi kết nối database hardcoded và các URL staging/production còn sót lại trong mã nguồn.

10. Câu Hỏi Thường Gặp & Xử Lý Sự Cố (FAQs)

Tôi có bắt buộc phải cài đặt Ghidra hoặc IDA Pro không?
Không bắt buộc! Đối với các ứng dụng JavaScript, Electron, .NET Assemblies, Web và cấu trúc file, REA có các parser tích hợp sẵn hoạt động hoàn toàn độc lập mà không cần bất kỳ công cụ ngoài nào. Bạn chỉ cần cài Ghidra hoặc Hopper khi muốn dịch ngược các file nhị phân C/C++/Rust compiled sang mã giả cấp cao.
Làm sao để biết REA đã kết nối thành công với Claude Code hay Cursor?
Trong Claude Code, bạn có thể gõ /tools hoặc hỏi: "Bạn có những công cụ nào của REA?". Nếu thấy danh sách các tool như analyze_target, decompile_function xuất hiện là kết nối đã thành công mỹ mãn!
Lỗi "Node version not supported" khi chạy lệnh setup?
REA yêu cầu Node.js phiên bản hiện đại (tối thiểu Node 20 LTS hoặc khuyên dùng Node 22/24). Hãy nâng cấp Node.js thông qua nvm (nvm install 22 && nvm use 22) hoặc tải bản mới nhất từ trang chủ nodejs.org.
Làm cách nào để cập nhật REA lên phiên bản mới nhất?
Nếu dùng qua NPX, bạn chỉ cần gọi npx rea-agents@latest setup. Nếu đã cài global, chạy lệnh: rea update hoặc npm update -g rea-agents.
REA khác gì so với việc copy code vào ChatGPT?
File binary hoặc minified bundle không thể copy-paste trực tiếp vào chat do kích thước khổng lồ và mã nhị phân không đọc được. REA đóng vai trò như "đôi mắt và đôi tay" của AI: mở ứng dụng, tìm kiếm đúng vị trí trọng yếu, trích xuất bằng chứng kỹ thuật và chỉ chuyển phần logic cốt lõi vào context của LLM.
