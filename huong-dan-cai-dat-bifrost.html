🚀 Cài Bifrost AI Gateway trên Ubuntu

Không Docker · Chạy 24/7 · Gán Domain + SSL

1 Cập nhật Ubuntu & cài gói cần thiết

Bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl git build-essential nginx

2 Cài Node.js 22 LTS

Bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs

# Kiểm tra
node -v   # → v22.x.x
npm -v    # → 10.x.x

3 Chạy thử Bifrost (30 giây)

Bash
npx -y @maximhq/bifrost

Lần đầu sẽ tải binary ~30-60s. Sau đó thấy Listening on :8080.

Mở trình duyệt: http://IP-VPS:8080 — Web UI sẽ xuất hiện.

⏹️ Tạm dừng bằng Ctrl+C trước khi qua bước sau.

4 Mở firewall

Bash
sudo ufw allow 8080/tcp
sudo ufw reload
sudo ufw status

5 Thêm Provider (OpenAI, Anthropic...)

Vào Web UI → Providers → Add Provider

Nhập API Key của từng provider. Ví dụ:

  • OpenAI → sk-xxxxxxxx
  • Anthropic → sk-ant-xxxx
  • DeepSeek, OpenRouter, Gemini...

6 Test API

Bash
# Xem danh sách model
curl http://localhost:8080/v1/models

# Test chat
curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4.1-mini",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
✅ Bifrost dùng chuẩn OpenAI API — SDK nào cũng chỉ cần đổi base_url.

7 Chạy Bifrost như service (24/7)

Tạo file service:

sudo nano /etc/systemd/system/bifrost.service
[Unit]
Description=Bifrost AI Gateway
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root
ExecStart=/usr/bin/npx -y @maximhq/bifrost
Restart=always
RestartSec=5
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target

Kích hoạt & chạy:

Bash
sudo systemctl daemon-reload
sudo systemctl enable bifrost
sudo systemctl start bifrost

# Kiểm tra
sudo systemctl status bifrost

# Xem log real-time
journalctl -u bifrost -f

8 Gán domain + SSL (Nginx)

Ví dụ domain: ai.example.com. Nhớ trỏ record A về IP VPS trước.

sudo nano /etc/nginx/sites-available/bifrost
server {
    listen 80;
    server_name ai.example.com;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}

Kích hoạt & SSL:

Bash
sudo ln -s /etc/nginx/sites-available/bifrost /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

# Cài SSL tự động
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d ai.example.com
✅ Certbot tự redirect HTTP → HTTPS và gia hạn tự động.

9 Dùng trong code

Python — OpenAI SDK
from openai import OpenAI

client = OpenAI(
    api_key="anything",
    base_url="https://ai.example.com/openai/v1"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response.choices[0].message.content)
Python — Anthropic SDK
from anthropic import Anthropic

client = Anthropic(
    api_key="anything",
    base_url="https://ai.example.com/anthropic"
)
✅ Chỉ cần đổi base_url, code cũ vẫn chạy.
