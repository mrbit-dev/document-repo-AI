1. FreeLLMAPI là gì?

FreeLLMAPI là một LLM gateway/router chạy local hoặc trên máy chủ riêng. Nó cho phép gom nhiều free tier và các endpoint OpenAI-compatible vào một API thống nhất. Thay vì cấu hình từng provider trong từng ứng dụng, client có thể gọi một endpoint FreeLLMAPI và để gateway xử lý routing, theo dõi rate limit và fallback giữa các provider/model.

Điểm cần hiểu rõ: FreeLLMAPI không tự cấp hàng tỷ token miễn phí. Các con số về model/token mà dự án công bố là tổng hợp năng lực free tier của các upstream provider mà người dùng kết nối.

Dự án hỗ trợ nhiều provider và có thể làm lớp trung gian cho các AI coding agent như Claude Code, Codex CLI, OpenCode, Aider, Cline, Continue và các client hỗ trợ API tương thích.

2. Lợi ích chính

  • Một endpoint: nhiều provider được gom vào một API duy nhất.
  • OpenAI-compatible: thuận tiện cho nhiều AI coding agent.
  • Fallback Chain: có thể chuyển sang endpoint/model khác khi endpoint ưu tiên gặp lỗi hoặc giới hạn.
  • Quản lý API key tập trung: provider key được cấu hình trong Dashboard.
  • Mã hóa key: provider API key được lưu trong database dưới dạng mã hóa.
  • Dashboard: quản lý provider, key, routing và các thiết lập liên quan.
  • Self-host: có thể chạy trên VPS riêng và không bắt buộc Docker.

4. Kiến trúc triển khai đề xuất

Mô hình phù hợp cho Ubuntu VPS:

Internet → Nginx :443 → 127.0.0.1:3001 → FreeLLMAPI → Upstream Providers
  • FreeLLMAPI lắng nghe nội bộ tại 127.0.0.1:3001.
  • Nginx đảm nhiệm HTTPS và reverse proxy.
  • Firewall không cần mở trực tiếp port 3001.
  • Client/agent bên ngoài truy cập qua domain HTTPS.

6. Hướng dẫn cài đặt FreeLLMAPI

Bước 1: Clone repository và cài dependencies

git clone https://github.com/tashfeenahmed/freellmapi.git
cd freellmapi
npm install

Bước 2: Sinh khóa mã hóa cho SQLite

cp .env.example .env
echo "ENCRYPTION_KEY=$(node -e "console.log(require('crypto').randomBytes(32).toString('hex'))")" >> .env
Rất quan trọng: ENCRYPTION_KEY dùng để mã hóa API key được lưu trong database. Hãy backup khóa này. Không được tùy tiện tạo khóa mới trên một installation đang có dữ liệu.

Bước 3: Khởi chạy Development

npm run dev

Development khởi chạy backend trên 3001 và Vite dashboard UI trên 5173, kèm HMR.

Production

npm run build
node server/dist/index.js

Sau khi build, server và dashboard cùng được phục vụ trên port 3001.

8. Setup code khi truy cập Dashboard từ máy remote

Khi tạo tài khoản đầu tiên từ một thiết bị remote, FreeLLMAPI có thể yêu cầu setup code. Đây là cơ chế bảo vệ việc tạo tài khoản đầu tiên.

Kiểm tra log:

sudo journalctl -u freellmapi -n 100 --no-pager

Hoặc lọc setup code:

sudo journalctl -u freellmapi --no-pager | grep -i -E "setup|code"

Nếu cần theo dõi realtime:

sudo journalctl -u freellmapi -f
Không nên xóa database hoặc tạo ENCRYPTION_KEY mới để xử lý setup code. Việc thay đổi khóa có thể làm các provider key đã mã hóa không thể giải mã.

9. Test API

Kiểm tra danh sách model

curl http://127.0.0.1:3001/v1/models \
  -H "Authorization: Bearer freellmapi-..."

Test Chat Completion

curl http://127.0.0.1:3001/v1/chat/completions \
  -H "Authorization: Bearer freellmapi-..." \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Xin chào"}]}'
Nếu API trả về danh sách model hoặc response hợp lệ, gateway cơ bản đã hoạt động.

10. Tạo systemd service

Thoát khỏi user freellmapi:

exit

Tạo service:

sudo nano /etc/systemd/system/freellmapi.service

Dán nội dung:

[Unit]
Description=FreeLLMAPI
After=network.target

[Service]
Type=simple
User=freellmapi
Group=freellmapi

WorkingDirectory=/home/freellmapi/freellmapi

EnvironmentFile=/home/freellmapi/freellmapi/.env

ExecStart=/usr/bin/node /home/freellmapi/freellmapi/server/dist/index.js

Restart=always
RestartSec=5

LimitNOFILE=65535

[Install]
WantedBy=multi-user.target

Lưu file:

Ctrl + O
Enter
Ctrl + X

11. Reload systemd và khởi động

sudo systemctl daemon-reload
sudo systemctl enable freellmapi
sudo systemctl start freellmapi

Kiểm tra trạng thái

sudo systemctl status freellmapi

Trạng thái mong muốn:

Active: active (running)

Ví dụ:

● freellmapi.service - FreeLLMAPI
     Loaded: loaded
     Active: active (running)

Xem log realtime

sudo journalctl -u freellmapi -f

12. Nginx + HTTPS cho Production

Nếu cần cho Claude Code, OpenCode, Codex hoặc máy khác truy cập từ Internet, nên đặt Nginx phía trước FreeLLMAPI và sử dụng HTTPS.

Client/Agent → https://DOMAIN → Nginx :443 → 127.0.0.1:3001 → FreeLLMAPI
Không nên mở trực tiếp port 3001 ra Internet. Chỉ nên expose Nginx trên 80/443 và để FreeLLMAPI chạy phía sau reverse proxy.

Ví dụ kiểm tra firewall:

sudo ufw status

Thông thường không cần:

sudo ufw allow 3001

14. Bảo mật và vận hành

  • Backup database và file .env.
  • Đặc biệt bảo vệ ENCRYPTION_KEY.
  • Không commit .env hoặc API key vào Git.
  • Không expose trực tiếp port 3001 nếu không cần thiết.
  • Dùng Nginx + HTTPS cho truy cập từ Internet.
  • Theo dõi log bằng journalctl khi có lỗi.
  • Free tier của upstream provider có thể thay đổi quota, model, rate limit hoặc điều kiện sử dụng.
  • FreeLLMAPI phù hợp cho gateway cá nhân/lab; không nên mặc định xem đây là hệ thống multi-tenant production.

16. Kết luận kỹ thuật

FreeLLMAPI có thể được xem như một lớp abstraction nằm giữa AI coding agent và nhiều LLM provider. Giá trị chính nằm ở việc hợp nhất endpoint, quản lý key, routing và fallback.

Đối với Ubuntu VPS, mô hình native + systemd + Nginx/HTTPS là một cách triển khai gọn, dễ kiểm soát và phù hợp khi không muốn dùng Docker. Hai thành phần cần đặc biệt bảo vệ là database và ENCRYPTION_KEY.
