🧠 Model Ternary-Bonsai-2-27B là gì & Nén Ternary là sao?

1. Model Ternary-Bonsai-2-27B là gì?

Ternary-Bonsai-2-27B là mô hình suy luận trí tuệ nhân tạo (reasoning model) có quy mô lên tới 27 tỷ tham số (27B) do tổ chức Prism-ML nghiên cứu và phát triển.

Model 27B Truyền Thống (FP16)
~54 GB
Cần 2-3 GPU cao cấp hoặc Server chuyên dụng
Ternary-Bonsai-2-27B (PTQ1_0)
~5.95 GB
Nhỏ hơn 9.3 lần - Chạy trọn vẹn trên RTX 3060 12GB!

Mặc dù bị nén hơn 9 lần, model vẫn giữ lại được 98.2% độ thông minh (intelligence retention) so với bản gốc 54GB trên các bài kiểm tra suy luận logic.

2. Nén Ternary (Lượng tử hóa tam phân) là sao?

Trong mạng nơ-ron AI, mỗi "khớp thần kinh" được lưu trữ bằng một trọng số (weight):

  • Chuẩn FP16 (16-bit): Mỗi trọng số là số thực dài (ví dụ: 0.481923...), có 65.536 trạng thái khác nhau $\rightarrow$ tốn rất nhiều RAM/VRAM.
  • Nén Ternary (Tam phân ~1.58-bit): Toàn bộ các con số phức tạp được quy ước chỉ nhận đúng 3 trạng thái duy nhất:
+1

Kích hoạt tích cực

(GPU thực hiện phép CỘNG)
0

Không kích hoạt

(GPU BỎ QUA - 0 tính toán)
-1

Ức chế / Đối nghịch

(GPU thực hiện phép TRỪ)
🚀
Tại sao Ternary lại là cuộc cách mạng?
Thay vì GPU phải thực hiện hàng ngàn tỷ phép nhân số thực cồng kềnh và nóng máy, với Ternary, GPU chỉ làm phép cộng và trừ cơ bản. Điều này giúp tăng tốc độ xử lý lên gấp nhiều lần, tiết kiệm điện năng và nhiệt độ card rất mát!
💡 Tại sao bắt buộc dùng bản fork của Prism-ML?

Model Ternary-Bonsai-2-27B sử dụng định dạng nén đặc biệt PTQ1_0 (Ternary 1-bit / 2-bit, mã tensor 143) kết hợp thuật toán biến đổi Walsh-Hadamard.

⚠️
Lưu ý: Bản llama.cpp chính thức trên GitHub hiện chỉ hỗ trợ kiểu tensor từ 0 đến 42. Nếu mở model bằng bản chính thức, chương trình sẽ báo lỗi:
gguf_init_from_reader: tensor 'output.weight' has invalid ggml type 143.

Kiểm tra CUDA Toolkit đã cài thành công chưa bằng cách mở PowerShell và gõ: nvcc --version
2 Tải mã nguồn Prism-ML Fork

Mở PowerShell và di chuyển vào thư mục làm việc (ví dụ D:\Llama.cpp) rồi clone mã nguồn về:

PowerShell 
cd D:\Llama.cpp
git clone https://github.com/PrismML-Eng/llama.cpp.git llama-prism
cd llama-prism
3 Biên dịch (Build) kích hoạt CUDA

Chạy 2 lệnh dưới đây để bắt đầu build bản hỗ trợ CUDA và tránh lỗi treo mạng khi tải giao diện npm:

PowerShell 
# Cấu hình build: Kích hoạt CUDA và tắt tự động npm ci để build siêu nhanh
cmake -B build -DGGML_CUDA=ON -DLLAMA_BUILD_UI=OFF

# Bắt đầu biên dịch (tận dụng toàn bộ nhân CPU)
cmake --build build --config Release -j
💡
Cờ -DLLAMA_BUILD_UI=OFF giúp bỏ qua bước UI: running npm ci, giúp thời gian build chỉ còn khoảng 1 phút thay vì bị nghẽn mạng!
4 Tải Model Ternary-Bonsai-2-27B (~5.95 GB)

Di chuyển vào thư mục chứa file chạy vừa build xong và tải model trực tiếp từ Hugging Face:

PowerShell 
cd D:\Llama.cpp\llama-prism\build\bin\Release

curl.exe -L -o "Ternary-Bonsai-2-27B-PTQ1_0.gguf" "https://huggingface.co/prism-ml/Ternary-Bonsai-2-27B-gguf/resolve/main/Ternary-Bonsai-2-27B-PTQ1_0.gguf"

(Nếu anh đã tải file này trước đó, chỉ cần Copy/Move file vào thư mục build\bin\Release là được).

5 Khởi động Web Chat & Chạy với GPU

Tại thư mục build\bin\Release, chạy lệnh sau:

PowerShell 
.\llama-server.exe -m Ternary-Bonsai-2-27B-PTQ1_0.gguf --port 8080 -ngl 99 -c 4096 --host 127.0.0.1

Khi màn hình báo HTTP server listening on http://127.0.0.1:8080, mở trình duyệt vào:

👉 http://localhost:8080
⚡ Mẹo: File chạy tự động 1-Click (.BAT)

Tạo file chay_bonsai_gpu.bat trong thư mục build\bin\Release với nội dung sau để lần sau chỉ cần click đúp là mở ngay:

chay_bonsai_gpu.bat 
@echo off
title Khoi dong Ternary-Bonsai-2-27B (CUDA GPU)
cd /d "%~dp0"
echo =======================================================
echo   DANG KHOI DONG SERVER BONSAI VOI GPU NVIDIA RTX...
echo   Giao dien web se tu dong mo tai localhost:8080
echo =======================================================
start http://localhost:8080
llama-server.exe -m Ternary-Bonsai-2-27B-PTQ1_0.gguf --port 8080 -ngl 99 -c 4096 --host 127.0.0.1
pause
