03 · Những thay đổi đáng chú ý

10 điểm nâng cấp quan trọng

01

Multi-gateway Connections

Desktop có registry cho nhiều Gateway và hỗ trợ profile-scoped refresh, phù hợp với local gateway, VPS gateway và nhiều môi trường riêng biệt.

02

MCP Health Checks

Khả năng kiểm tra trạng thái MCP tốt hơn, cùng deep links giúp quản lý MCP thuận tiện hơn trong Desktop.

03

Persisted Model Routes

Model/provider routing được lưu bền vững hơn, hữu ích khi làm việc với nhiều provider và nhiều session.

04

Profile-scoped Auth

Credential resolution theo scope của profile giúp giảm tình trạng auth bị dùng chéo giữa các profile.

05

Gateway /loop

Hỗ trợ loop completion tốt hơn cho workflow agent có nhiều vòng suy luận, tool call và kiểm tra kết quả.

06

Telegram DM Topics

Tổ chức hội thoại Telegram tốt hơn khi agent được sử dụng như một bot hoặc remote assistant.

07

Prompt Caching

Hỗ trợ prompt caching cho LiteLLM Claude trên OpenAI wire, hữu ích với context và tool definitions lớn.

08

Cron Hardening

Automation định kỳ được tiếp tục harden, phù hợp với các agent chạy task tự động.

09

Windows Update Probes

Cải thiện quá trình phát hiện update và độ ổn định của installer/update path trên Windows.

10

Installer Robustness

Độ bền của installer và update flow được cải thiện cho Linux và Windows.

06 · Lưu ý version

v0.20.2 là patch release

v0.20.2 không phải một major feature release độc lập. Đây là patch release, tập trung vào fix, hardening, stability và integration improvements. Release note cũng cho biết changelog được tuyển chọn đầy đủ từ v0.20.0 sẽ được trình bày trong v0.21.0.

07 · Có nên nâng cấp?

Khuyến nghị

✓

Nên upgrade

Nếu đang ở v0.16 và dùng Hermes cho VPS, MCP, coding agent, nhiều provider, profile, Telegram/Discord, cron hoặc Desktop.

⚠

Backup trước

Backup config, auth, profiles, MCP, custom providers, fallback providers, skills, memory, cron và gateway trước khi nâng cấp hệ thống đang chạy.

→

Nếu không gấp

Có thể theo dõi v0.21.0 nếu muốn một release có changelog được tổng hợp đầy đủ từ v0.20.0 trở đi.

Kết luận

Từ “Agent” đến “Agent Platform”

Khoảng cách từ Hermes Agent v0.16.0 đến v0.20.2 là rất đáng kể. Nếu v0.16 tập trung đưa Desktop, Profiles, Gateway và MCP thành một hệ thống agent hoàn chỉnh, thì v0.20.2 tiếp tục củng cố nền tảng theo hướng multi-gateway, multi-profile, provider routing, automation và production stability.

VERDICT
Nếu đang dùng v0.16 → nên nâng cấp lên v0.20.2

Đặc biệt khi anh sử dụng MCP, nhiều model/provider, profiles, Gateway hoặc automation.
