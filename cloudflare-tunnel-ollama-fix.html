Hướng Dẫn Fix Lỗi Cloudflare Tunnel & Ollama

Trọn bộ giải pháp: Fix lỗi 403 Forbidden, Script Auto-Reconnect Quick Tunnel, Script Anti-Idle giữ phiên Kaggle và Named Tunnel có Token cố định.

1
Cấu hình Ollama Host & Origins (Chống lỗi 403 Forbidden)

Trước khi chạy ollama serve, cần mở CORS và cho phép nhận kết nối từ bên ngoài:

bash / terminal 
# Bật cho phép mọi IP và mọi domain gửi request đến Ollama
export OLLAMA_HOST="0.0.0.0:11434"
export OLLAMA_ORIGINS="*"

# Chạy Ollama ngầm
nohup ollama serve > /tmp/ollama.log 2>&1 &
💡 Kiểm tra: Gõ lệnh curl http://localhost:11434 nếu thấy trả về Ollama is running là hoàn tất!
2
Script Auto-Reconnect Quick Tunnel (Kèm fix --http-host-header)

Dành cho anh em dùng Quick Tunnel miễn phí (không cần tên miền riêng). Script tự động kèm cờ --http-host-header="localhost:11434" để triệt tiêu lỗi 403, đồng thời tự động kết nối lại ngay lập tức nếu bị rớt mạng:

python (jupyter / kaggle cell) 
import subprocess, time, re, os

# 1. Bật biến môi trường chống lỗi 403 Forbidden
os.environ["OLLAMA_HOST"] = "0.0.0.0:11434"
os.environ["OLLAMA_ORIGINS"] = "*"

# 2. Khởi chạy Ollama ngầm nếu chưa chạy
subprocess.Popen(["nohup", "ollama", "serve"], stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
time.sleep(2)

def start_tunnel():
    print("[+] Đang khởi chạy Cloudflare Tunnel...")
    # Thêm --http-host-header localhost:11434 để fix lỗi 403 Forbidden
    cmd = [
        "cloudflared", "tunnel",
        "--url", "http://127.0.0.1:11434",
        "--http-host-header", "localhost:11434",
        "--metrics", "localhost:45678"
    ]
    proc = subprocess.Popen(cmd, stdout=subprocess.PIPE, stderr=subprocess.STDOUT, text=True)
    
    url = None
    for line in proc.stdout:
        match = re.search(r'https://[a-zA-Z0-9-]+\.trycloudflare\.com', line)
        if match:
            url = match.group(0)
            print(f"\n[🔥 KẾT NỐI THÀNH CÔNG] Domain Ollama của bạn:")
            print(f"👉 {url}\n")
            break
    return proc, url

# Vòng lặp giám sát: nếu tunnel chết sẽ tự động bật lại ngay lập tức
while True:
    proc, url = start_tunnel()
    proc.wait() # Chờ tiến trình
    print("[!] Tunnel bị ngắt kết nối. Đang tự động kết nối lại sau 5 giây...")
    time.sleep(5)

Script Chống Kaggle / Colab Tự Ngắt (Anti-Idle Keep-Alive)

Kaggle thường tự động tắt phiên sau 40–60 phút nếu không có tương tác chuột. Chạy đoạn script này ở 1 cell riêng để giữ kernel luôn active suốt thời gian GPU được cấp:

python (jupyter / kaggle cell) 
import time
from IPython.display import clear_output

# Script giữ kernel Kaggle luôn active chạy tối đa thời gian của GPU
print("[*] Đang kích hoạt chế độ Keep-Alive...")
start_time = time.time()
while True:
    elapsed = int(time.time() - start_time)
    hours, remainder = divmod(elapsed, 3600)
    minutes, seconds = divmod(remainder, 60)
    clear_output(wait=True)
    print(f"[🔥 VPS AI ONLINE] Thời gian đã chạy: {hours:02d}:{minutes:02d}:{seconds:02d} / 12:00:00")
    time.sleep(30)

Named Tunnel Có Token (Cố định tên miền riêng, không bao giờ đổi link)

Nếu có tên miền riêng thêm vào Cloudflare Zero Trust (one.dash.cloudflare.com), anh em tạo Tunnel và chạy bằng Token. Cloudflare sẽ tự động quản lý kết nối và giữ tên miền cố định vĩnh viễn:

bash / terminal 
# 1. Cài đặt cloudflared phiên bản mới nhất
curl -fsSL https://pkg.cloudflare.com/cloudflare-main.gpg | sudo tee /usr/share/keyrings/cloudflare-main.gpg >/dev/null
echo 'deb [signed-by=/usr/share/keyrings/cloudflare-main.gpg] https://pkg.cloudflare.com/cloudflared any main' | sudo tee /etc/apt/sources.list.d/cloudflared.list
sudo apt-get update && sudo apt-get install -y cloudflared

# 2. Chạy tunnel bằng Token (chạy ngầm ổn định, tự động reconnect khi rớt mạng)
nohup cloudflared tunnel run --token <ĐIỀN_TOKEN_CLOUDFLARE_VÀO_ĐÂY> > /tmp/tunnel.log 2>&1 &
📌 Lưu ý cấu hình Zero Trust: Khi tạo Public Hostname, chọn Service Type là HTTP, URL là localhost:11434. Trong mục Additional application settings → HTTP Settings, nhập HTTP Host Header là localhost:11434.
