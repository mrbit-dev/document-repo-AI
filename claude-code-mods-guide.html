4. Gatekeeper (Execution Gate): "Cổng gác" kiểm duyệt mọi câu lệnh trước khi chạy trên máy tính.

01

Token Weather

Anthropic Official Vị trí: Top Strip
⏱ Video 1:01

Claude có một bộ nhớ làm việc (working memory / context window). Khi bộ nhớ này bị lấp đầy, Claude sẽ tự động ép chặt các tin nhắn cũ và bắt đầu quên mất các chi tiết quan trọng mà bạn đã yêu cầu lúc đầu.

Token Weather đặt một bản báo cáo thời tiết trực quan cho bộ nhớ này ngay phía trên ô nhập câu lệnh:

  • Clear (0% - 30%): Bầu trời trong xanh, bộ nhớ thông thoáng, Claude nhớ toàn bộ chi tiết.
  • Cloudy (30% - 70%): Nhiều mây, đã nạp tài liệu lớn (ví dụ đọc kho lưu trữ lớn nhảy lên 37%).
  • Storm (70%+): Cơn bão ập đến! Cảnh báo đỏ: Hãy gõ lệnh /compact hoặc mở phiên chat mới để tránh mất dữ liệu.
  • Các vạch phân đoạn nhỏ cho biết chính xác từng câu hỏi của bạn tiêu tốn thêm bao nhiêu token (+21.7k...).
⛅ Thử Nghiệm: Token Weather 0 / 200k tokens
☀️ Clear (Trời quang) 0%

Bộ nhớ hoàn toàn sạch. Sẵn sàng nhận dự án lớn!

2. Khởi chạy kèm Mod (hoặc chép vào ~/.claude/mods/):

"Make me a mod that displays a working memory token weather report (Clear, Cloudy, Storm) above the prompt box."

Blast Radius

Anthropic Official Vị trí: Gatekeeper Hook
⏱ Video 1:32

Khi bạn yêu cầu Claude: "Hãy dọn dẹp dự án của tôi", Claude có thể quyết định xóa toàn bộ một thư mục chứa hàng chục tệp tin mà bạn không hề hay biết.

Blast Radius đóng vai trò như một chiếc phanh khẩn cấp: Giữ lại câu lệnh và tính toán chính xác bán kính tàn phá trước khi có bất kỳ tệp tin nào bị chạm vào:

  • Liệt kê chi tiết số lượng file bị ảnh hưởng (ví dụ: 84 files, dung lượng ~604 KB).
  • Hiển thị danh sách tên từng tệp tin sẽ bị xoá vĩnh viễn.
  • Chặn cả các lệnh git phá huỷ như git push --force hay git reset --hard làm mất code chưa lưu.
  • Bạn có toàn quyền bấm Cancel để huỷ bỏ lệnh ngay lập tức mà không mất dù chỉ 1 byte!

03

Safety Net

Tự Xây Dựng (Custom) Vị trí: Security Gate
⏱ Video 1:59

Claude Code nguyên bản đã từ chối xoá toàn bộ thư mục gốc dự án, nhưng vẫn còn nhiều kẽ hở nghiêm trọng. Safety Net được tạo ra để lấp đầy toàn bộ những khoảng trống đó chỉ trong một cơ chế bảo vệ.

Trong thử nghiệm thực tế, khi tác giả cố tình yêu cầu Claude thực hiện 3 hành động nguy hiểm cùng một lúc:

  • Đọc file .env: Nơi lưu trữ API keys, mật khẩu database -> Bị Safety Net chặn tức thì, bảo vệ khóa bí mật tuyệt đối.
  • Lệnh xóa bảng cơ sở dữ liệu: Phát hiện câu lệnh DROP TABLE users; -> Lập tức huỷ lệnh, bảng dữ liệu vẫn nguyên vẹn.
  • Chạy script internet không rõ nguồn gốc: Chặn đứng các câu lệnh curl | sh hoặc wget | bash.
🛡️ Nhật Ký Bảo Vệ Của Safety Net 3 BLOCKS
📄 Đọc tệp .env / secrets BỊ CHẶN (BLOCKED)
🗄️ SQL: DROP TABLE customers; BỊ CHẶN (BLOCKED)
🌐 Shell: curl https://... | sh BỊ CHẶN (BLOCKED)

✓ Kết quả: Claude hoàn toàn không đọc được API key và database không hề suy suyển.

📦 Cách Cài Đặt Chuẩn: Safety Net ✨ Mod Tự Tạo (Custom Prompt Mod)
1. Tạo trực tiếp bằng Prompt trong Claude Code (Khuyên dùng):
"Make me a security mod that blocks reading .env secret files, prevents DROP TABLE queries, and blocks running curl piped to sh."
2. Hoặc khởi tạo khung plugin cục bộ trong dự án:
claude plugin init safety-net
🛡️ Lệnh thẩm định mã sau khi mod được lưu vào ~/.claude/mods/:
claude plugin validate ~/.claude/mods/safety-net

Replay Theater

Anthropic Official Lệnh: /replay
⏱ Video 3:08

Sau khi Claude thực hiện hàng loạt chỉnh sửa trên nhiều file cùng lúc, làm sao để bạn kiểm soát và hiểu được Claude đã sửa những gì mà không cần mở Git diff thủ công?

Chỉ cần gõ lệnh /replay, Replay Theater sẽ mở ra một "rạp chiếu phim" tua lại từng dòng code:

  • Cho phép bạn bấm duyệt qua từng bước sửa đổi một cách tuần tự (step-by-step).
  • Màu Xanh lá biểu thị các dòng mã mới được thêm vào.
  • Màu Đỏ biểu thị các dòng mã cũ đã bị lược bỏ hoặc sửa đổi.
  • Cảm giác trực quan hệt như đang bấm tua lại một cuốn băng video ghi lại từng thao tác của Claude.

Quick Buttons

Tự Xây Dựng (Custom) Lệnh: /buttons
⏱ Video 3:24

Bạn chán ngấy việc mỗi ngày phải lặp đi lặp lại những câu prompt quen thuộc? Gõ lệnh /buttons và một menu gồm 6 nút bấm một chạm sẽ hiện ra ngay lập tức:

  • 1. Explain it simply: Giải thích đoạn code/logic này thật đơn giản.
  • 2. Test it & fix it: Chạy thử nghiệm và tự động sửa các lỗi phát sinh.
  • 3. Save a checkpoint: Lưu lại điểm mốc commit git an toàn.
  • 4. What changed?: Liệt kê tất cả file thay đổi bằng đúng 1 dòng tóm tắt mỗi file.
  • 5. Find my bugs: Quét tìm lỗ hổng tiềm ẩn trong toàn bộ code vừa viết.
  • 6. What next?: Đề xuất bước tiếp theo hợp lý nhất cần làm.
  • Tùy biến 100%: Bạn có thể dễ dàng thay thế 6 nút này bằng những câu prompt riêng của dự án bạn!

08

/better (Prompt Enhancer)

Tự Xây Dựng (Custom) Lệnh: /better
⏱ Video 3:45

Chúng ta thường gõ những câu prompt rất sơ sài như: "make the order page nicer" (làm trang đặt hàng đẹp hơn). Điều này khiến AI đoán mò và thường cho ra kết quả không như ý muốn.

Chỉ cần gõ /better <ý tưởng thô>, mod sẽ tự động tái cấu trúc câu nói thô thiển của bạn thành một bản đặc tả kỹ thuật chuẩn chỉnh gồm 4 phần:

  • Goal (Mục tiêu): Xác định chính xác kết quả đầu ra cần đạt được.
  • Details (Chi tiết): Danh sách các yêu cầu UI/UX, bảng màu, hiệu ứng, responsive.
  • Done-when (Tiêu chuẩn xong): Tiêu chí nghiệm thu rõ ràng (không lỗi console, pass test).
  • Plan first (Lập kế hoạch trước): Bắt buộc Claude phải trình bày dàn ý kế hoạch trước khi bắt tay viết code.
  • Đặc biệt: Kết quả rơi thẳng vào ô gõ prompt để bạn xem lại và chỉnh sửa trước khi gửi!
🪄 Trải Nghiệm Lệnh /better PROMPT GENERATOR
🎯 GOAL: Hiện đại hóa giao diện trang đặt hàng (Order Page).
📋 DETAILS: Bổ sung card sản phẩm bo tròn, giỏ hàng cố định bên phải, micro-animations khi chọn số lượng và dark mode.
✅ DONE-WHEN: Mọi tương tác mượt mà ở mobile & desktop, không có lỗi JS console.
📝 PLAN FIRST: Hãy liệt kê các thành phần giao diện cần sửa trước khi chỉnh code.
📦 Cách Cài Đặt Chuẩn: /better ✨ Mod Tự Tạo (Custom Prompt Mod)
1. Tạo trực tiếp bằng Prompt trong Claude Code (Khuyên dùng):
"Make me a mod providing /better command that rewrites rough prompt into structured Goal, Details, Done-when, and Plan first, inserting into input box."
2. Hoặc khởi tạo khung plugin cục bộ trong dự án:
claude plugin init better-prompt
🪄 Lệnh thẩm định mã sau khi mod được lưu vào ~/.claude/mods/:

Tự Tạo Mod Riêng Của Bạn Chỉ Bằng 1 Câu Lệnh!

Điều kỳ diệu nhất ở tính năng Mods của Claude Code: Bạn không cần phải là một lập trình viên phần mềm chuyên sâu để tự chế tạo mod. Chỉ cần mở Claude Code lên và mô tả mong muốn của bạn bằng ngôn ngữ tự nhiên.

1

Mô tả ý tưởng cho Claude Code

Mở phiên làm việc Claude Code và gõ một câu lệnh tự nhiên mô tả mod bạn muốn tạo:

"Make me a mod that shows how long I've been working today above the prompt."

(Tạo cho tôi một mod hiển thị thời gian tôi đã làm việc hôm nay nằm ở thanh phía trên ô prompt).

2

Claude Code tự sinh mã trong 15-20 giây

Claude sẽ tự động viết toàn bộ cấu trúc file plugin/mod, đăng ký hooks tương ứng và thông báo hoàn tất, sau đó hỏi: "Reload to apply changes?".

3

Xác nhận Reload và Sử dụng ngay!

Bạn chọn Yes (hoặc gõ reload). Ngay lập tức, trên ô prompt xuất hiện đồng hồ đếm giờ làm việc: working today: 0 minutes. Đồng hồ bắt đầu chạy ngay lập tức!

Hướng Dẫn Cài Đặt & Cảnh Báo Bảo Mật

Những lưu ý sinh tử bạn nhất định phải biết trước khi tải và cài đặt bất kỳ Mod nào từ cộng đồng.

⚠️
CẢNH BÁO BẢO MẬT TỐI QUAN TRỌNG TỪ TÁC GIẢ

Một Mod trong Claude Code chạy với toàn bộ quyền hạn hệ thống của chính tài khoản máy tính của bạn (Full User Permissions)! Nếu bạn cài đặt một Mod độc hại từ nguồn không rõ ràng, nó hoàn toàn có thể đọc trộm khóa SSH, mật khẩu trình duyệt, mã nguồn cá nhân hoặc gửi dữ liệu ra bên ngoài máy tính của bạn.

💡 Lưu Ý Kỹ Thuật: Vì Sao Không Thể Gõ Lệnh Dạng github:...?

Nếu bạn thử chạy lệnh claude plugin validate github:... hoặc claude plugin install github:... thì Claude Code sẽ báo lỗi ngay lập tức vì 2 nguyên nhân cốt lõi:

  • Lệnh claude plugin validate <path>: Chỉ nhận đường dẫn thư mục/tệp tin cục bộ trên máy tính (local path như ./mods/ten-mod hoặc ~/.claude/mods/ten-mod), hoàn toàn không nhận đường dẫn từ xa dạng URI github:.... Nếu truyền github:..., CLI hiểu đó là một tên file nội bộ và báo lỗi File not found.
  • Lệnh claude plugin install <plugin>: Chỉ tìm plugin từ Marketplace đã được đăng ký (mặc định chỉ có anthropic-plugin-directory). Để cài từ kho ngoài, quy trình chuẩn là: claude plugin marketplace add <repo> rồi mới claude plugin install <name>@<marketplace>.
  • Về các Custom Mods của video: Kênh DEVKIT AI không duy trì một GitHub repo công khai dạng devkit-ai/claude-mods. Trong video thực tế, tác giả tận dụng khả năng tự tạo mod trực tiếp của Claude Code bằng câu Prompt: "Make me a mod that..." để Claude Code tự sinh code và nạp thẳng vào hệ thống!
🔍

1. Luôn Chạy Lệnh Thẩm Định (Validate)

Trước khi cài đặt bất kỳ mod nào, hãy chạy lệnh thẩm định sau để quét tĩnh mã nguồn:

claude plugin validate <path-hoặc-tên-mod>

Lệnh này sẽ liệt kê tất cả các file, tài nguyên và quyền hệ thống mà mod sẽ chạm vào mà KHÔNG thực thi mod đó.

🤝

2. Chỉ Cài Đặt Từ Nguồn Đáng Tin Cậy

Ưu tiên các mod chính thức từ Anthropic Playground hoặc các tác giả có độ uy tín cao trong cộng đồng. Đừng bao giờ chạy các lệnh cài đặt mod được chia sẻ từ tin nhắn ẩn danh trên mạng xã hội.

📂

3. Kiểm Tra Thư Mục Lưu Trữ

Các Mod thường nằm trong thư mục ~/.claude/mods/ (toàn cục) hoặc .claude/mods/ (riêng từng dự án). Bạn luôn có thể mở thư mục này ra để tự đọc mã nguồn trước khi bật lên.

Hỏi Đáp

Các Câu Hỏi Thường Gặp (FAQ)

⚡ Mod có làm chậm Claude Code không?

Hầu hết các Mod được tối ưu siêu nhẹ (như Plain English sử dụng model Claude 3.5 Haiku chỉ tốn khoảng 1 giây để phản hồi, còn các gatekeeper như Blast Radius chạy code kiểm tra cục bộ tức thì trong vài mili-giây) nên không ảnh hưởng đến tốc độ làm việc.

🔄 Tôi cần phiên bản nào để dùng Mods?

Bạn cần Claude Code phiên bản 2.1.287 trở lên (phiên bản tác giả thử nghiệm trong video là 2.1.289). Tính năng Mods được bật sẵn mặc định mà không cần thêm cờ cấu hình phức tạp nào.

👥 Tôi có thể chia sẻ Mod cho đồng đội trong team không?

Có! Bạn có thể lưu các file mod vào thư mục .claude/mods/ ngay trong git repository của dự án. Khi đồng đội clone dự án về, Claude Code sẽ tự động nhận diện và áp dụng các mod này cho cả nhóm.

🛑 Làm sao để tắt hoặc gỡ bỏ một Mod khi không dùng?

Bạn chỉ cần xóa file hoặc thư mục của mod đó trong .claude/mods/ hoặc dùng lệnh claude plugin remove <mod-name> rồi khởi động lại Claude Code.
