01 / TỔNG QUAN NGUYÊN LÝ

OpenJEV Là Gì? Bản Chất Thật Sự Ra Sao?

Được phát triển dựa trên mô hình Jev của TypeSafe AI (vận hành qua quỹ token $JEV), OpenJEV là một API AI chuyên biệt duy nhất: Không sinh văn bản tán gẫu, chỉ ra quyết định có cấu trúc toán học.

Cấu Trúc Hoạt Động

Endpoint Duy Nhất: POST /v1/systemone

Khác với OpenAI hay Anthropic có hàng chục endpoint phức tạp, OpenJEV chỉ có đúng 1 cổng API nhận 2 thành phần chính:

  • state (Ngữ cảnh): Dữ liệu thô bạn gửi lên (một chuỗi văn bản, JSON object, danh sách bản ghi, log terminal, commit git...).
  • questions (Câu hỏi định kiểu): Bộ các phán đoán độc lập cần AI giải quyết trên cùng một ngữ cảnh state.
  • answers (Kết quả): Dữ liệu có cấu trúc tuyệt đối, không có chữ thừa, kèm theo xác suất (probabilities) và độ tin cậy (confidence).
Triết Lý Thiết Kế

Ẩn Dụ: "Vị Trọng Tài Bấm Nút Trắc Nghiệm"

Nếu bạn xem ChatGPT hay Claude là một nhà văn / luật sư biện hộ thích nói dài, giải thích vòng vo và đôi khi "bịa đặt" (hallucination); thì OpenJEV giống như một trọng tài bấm máy tính điện tử:

"Ném dữ liệu vào ➔ Tôi chỉ tick đúng vào ô A, B hoặc C và cho bạn biết điểm số chắc chắn là bao nhiêu phần trăm để bạn viết lệnh if...else trong code."

02 / SO SÁNH ĐỐI CHIẾU

OpenJEV Khác Gì Với AI Agent (Claude Code, Antigravity, OpenCode)?

Rất nhiều người nhầm lẫn OpenJEV là một "AI Agent thay thế Claude". Thực tế, OpenJEV sinh ra để làm bộ não phản xạ nhanh (System 1) bổ trợ cho Agent.

Tiêu Chí So Sánh AI Agent Truyền Thống (Claude Code, Antigravity) OpenJEV (Decision Engine)
Bản chất Tác tử tự hành (Agent) biết đọc file, sửa file, gõ terminal, lập kế hoạch. Bộ máy phán đoán (Micro Decision Engine) trả lời trắc nghiệm & chấm điểm.
Kiểu tư duy System 2 (Slow & Deep Thinking): Suy nghĩ nhiều bước, lập luận sâu nhưng tốn thời gian (5-30s). System 1 (Fast Reflex): Phản xạ tức thì trong mili-giây, phân loại dứt khoát.
Đầu ra (Output) Văn bản tự do (Markdown, hội thoại, sinh code). Dễ bị sai format JSON nếu không ràng buộc. Dữ liệu kiểu chặt chẽ (Choice, Score, Noul) + Phân phối xác suất (Softmax/Probabilities).
Độ tự tin (Confidence) Không có điểm số chính xác. Thường nói rất tự tin dù đang trả lời sai. Có điểm số xác suất thật (0.0 - 1.0). Giúp code biết khi nào AI phân vân để dừng lại.
Chi phí & Token Tốn nhiều context tokens do phải mang theo cả lịch sử chat và prompt hướng dẫn. Cực kỳ gọn nhẹ, chỉ gửi đúng dữ liệu cần thẩm định.
Mối quan hệ 🤝 Cộng tác hoàn hảo: Agent dùng OpenJEV như một "bộ lọc an toàn" và "la bàn phân loại" trước khi hành động.
03 / KIẾN TRÚC DỮ LIỆU

3 Kiểu Quyết Định Cốt Lõi (Primitives)

OpenJEV tối giản hóa toàn bộ thế giới quyết định của phần mềm thành 3 dạng câu hỏi toán học:

01 / Type: choice

Phân Loại (Choice)

Chọn 1 nhãn chính xác nhất trong danh sách tiêu chí bạn định nghĩa trước (hỗ trợ tối đa 255 lựa chọn).

Output trả về
{ "choice": "billing", "probabilities": { "billing": 0.94, "tech": 0.04, "sales": 0.02 }, "confidence": 0.85 }

👉 Ứng dụng: Phân luồng ticket hỗ trợ, phân loại loại task (bugfix / frontend / devops).

02 / Type: score

Chấm Thang Điểm (Score)

Đánh giá theo một thước đo có thứ bậc từ 0 đến N-1 (tối đa 10 bậc). Trả về số thực, có thể nằm giữa các bậc.

Output trả về
{ "score": 1.75, "legend": { "0": "An toàn", "1": "Cần lưu ý", "2": "Cực nguy hiểm" }, "confidence": 0.91 }

👉 Ứng dụng: Đánh giá độ nguy hiểm lệnh bash, chấm điểm tiềm năng khách hàng (lead score).

03 / Type: noul

Xác Suất Đúng/Sai (Noul)

Đánh giá câu hỏi Có / Không (Yes/No) dưới dạng một số thực xác suất từ 0.0 đến 1.0 (gần 1 là Có, gần 0 là Không).

Output trả về
{ "urgent": { "type": "noul", "noul": 0.96 } }

👉 Ứng dụng: Kiểm tra tin nhắn có khẩn cấp không? Lệnh này có xoá dữ liệu không? Đoạn diff này có leak password không?

04 / KỊCH BẢN THỰC CHIẾN

OpenJEV Được Ứng Dụng Như Thế Nào Trong Thực Tế?

1. Chốt chặn an toàn Terminal (Guardrails)

Trước khi Agent (như Claude Code hoặc Antigravity) tự ý bấm phím chạy một lệnh Bash/Powershell nguy hiểm như rm -rf, git reset --hard, DROP TABLE:

Lệnh ➔ OpenJEV chấm điểm nguy hiểm (Score) ➔ Nếu Score > 1.2 ➔ Khóa cứng terminal và yêu cầu người dùng xác nhận bằng tay.

2. Định tuyến Task tự động (Agent Triage)

Bạn ném cho AI một yêu cầu hỗn hợp. Agent dùng OpenJEV để phân loại prompt:

Prompt: "Sửa lỗi crash khi upload ảnh ở server production" ➔ Choice: "bugfix_backend" ➔ Agent chỉ nạp đúng rule backend & file log, tránh nạp linh tinh làm tràn context.

3. Kiểm duyệt Code Review & PR Tự Động

Khi lập trình viên tạo Pull Request hoặc lưu file:

Git Diff ➔ OpenJEV hỏi Noul: "Có chứa API Key, JWT token, hay vi phạm quy tắc bảo mật OWASP không?" ➔ Noul: 0.88 ➔ Từ chối merge code ngay lập tức.

4. Tính năng nghiệp vụ bên trong Website/App

Dùng trực tiếp trong backend PHP, NodeJS, Python của trang web:

Bình luận của người dùng ➔ OpenJEV phân loại cảm xúc (Tích cực/Tiêu cực/Spam lừa đảo) ➔ Ẩn bình luận nếu xác suất spam > 90%.

05 / TRIỂN KHAI TOÀN CỤC - CÁCH 1

Cách Tạo Global CLI Script Trên Windows

Cài đặt 1 lần duy nhất trên máy tính. Bất kể bạn mở dự án nào, chỉ cần gõ lệnh jev "nội dung" trong terminal hoặc để AI gọi công cụ chạy lệnh.

1

Tạo thư mục công cụ trên máy

Mở PowerShell và tạo thư mục chứa công cụ toàn cục (ví dụ: C:\my-tools):

PowerShell
New-Item -ItemType Directory -Force -Path "C:\my-tools"
2

Viết file thực thi C:\my-tools\jev.mjs

Tạo file JavaScript ES Module để nhận input từ dòng lệnh và gọi thẳng tới OpenJEV:

C:\my-tools\jev.mjs
import process from "node:process"; const inputState = process.argv.slice(2).join(" "); const apiKey = process.env.OPENJEV_API_KEY; if (!inputState) { console.error("❌ Lỗi: Hãy nhập nội dung cần kiểm tra. Ví dụ: jev \"rm -rf public/\""); process.exit(1); } if (!apiKey) { console.error("❌ Lỗi: Chưa đặt biến môi trường OPENJEV_API_KEY"); process.exit(1); } try { const res = await fetch("https://api.openjev.sh/v1/systemone", { method: "POST", headers: { "Authorization": `Bearer ${apiKey}`, "Content-Type": "application/json" }, body: JSON.stringify({ model: "openjev", state: inputState, questions: { danger_score: { type: "score", instructions: "Đoạn lệnh hoặc mã này có nguy cơ phá hoại/xoá dữ liệu không?", criteria: ["An toàn", "Lưu ý", "Nguy hiểm nghiêm trọng"] }, need_confirm: { type: "noul", instructions: "Lệnh này có cần hỏi xác nhận trước khi chạy không?" } } }) }); const data = await res.json(); console.log(JSON.stringify(data.answers, null, 2)); } catch (err) { console.error("Lỗi kết nối:", err.message); }
3

Tạo file lệnh Batch C:\my-tools\jev.cmd

File này giúp Windows hiểu lệnh jev ở bất kỳ cửa sổ CMD/PowerShell nào:

C:\my-tools\jev.cmd
@echo off node "C:\my-tools\jev.mjs" %*
4

Thêm vào PATH và lưu API Key

Chạy lệnh sau 1 lần trên PowerShell (quyền Admin hoặc User):

PowerShell
# Thêm C:\my-tools vào biến môi trường PATH [Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path", "User") + ";C:\my-tools", "User") # Lưu API Key OpenJEV của bạn [Environment]::SetEnvironmentVariable("OPENJEV_API_KEY", "your_api_key_here", "User")

🎉 Hoàn tất! Từ nay ở bất kỳ thư mục dự án nào, bạn (hoặc Claude Code / Antigravity) chỉ cần gõ: jev "git reset --hard HEAD~1" là kết quả phân tích in ra tức thì!

06 / TRIỂN KHAI TOÀN CỤC - CÁCH 2

Cách Tạo MCP Server Toàn Cục (Model Context Protocol)

Đây là cách đẳng cấp và mượt mà nhất cho AI Agent: Biến OpenJEV thành một công cụ bản địa (Native Tool) có sẵn trong bộ nhớ của Antigravity hay Claude Code.

Tại sao MCP lại vượt trội hơn?

Khi dùng MCP, bạn không cần phải ra lệnh "Hãy mở terminal gõ `jev...`". Thay vào đó, AI Agent sẽ có thêm công cụ openjev_decide. Khi bạn hỏi: "Hãy kiểm tra xem hàm login này có an toàn không?", Agent sẽ tự động gọi tool `openjev_decide` trong tiềm thức và trả lời bạn ngay lập tức!

1

Khởi tạo dự án MCP Server

Tạo thư mục C:\my-tools\mcp-openjev và cài đặt thư viện chuẩn của Anthropic:

Terminal
mkdir C:\my-tools\mcp-openjev cd C:\my-tools\mcp-openjev npm init -y npm install @modelcontextprotocol/sdk
2

Viết mã nguồn MCP Server (index.mjs)

Khai báo tool openjev_decide bằng cú pháp chuẩn MCP:

C:\my-tools\mcp-openjev\index.mjs
import { Server } from "@modelcontextprotocol/sdk/server/index.js"; import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js"; import { CallToolRequestSchema, ListToolsRequestSchema } from "@modelcontextprotocol/sdk/types.js"; const server = new Server({ name: "openjev-server", version: "1.0.0" }, { capabilities: { tools: {} } }); // 1. Khai báo công cụ cho AI nhận diện server.setRequestHandler(ListToolsRequestSchema, async () => ({ tools: [{ name: "openjev_decide", description: "Ra quyết định cấu trúc, phân loại hoặc chấm điểm rủi ro bằng OpenJEV", inputSchema: { type: "object", properties: { state: { type: "string", description: "Đoạn văn bản/mã nguồn cần đánh giá" }, question_instruction: { type: "string", description: "Câu hỏi phán đoán" }, question_type: { type: "string", enum: ["choice", "score", "noul"] } }, required: ["state", "question_instruction", "question_type"] } }] })); // 2. Xử lý khi AI gọi công cụ server.setRequestHandler(CallToolRequestSchema, async (request) => { if (request.params.name !== "openjev_decide") throw new Error("Tool không tồn tại"); const { state, question_instruction, question_type } = request.params.arguments; const res = await fetch("https://api.openjev.sh/v1/systemone", { method: "POST", headers: { "Authorization": `Bearer ${process.env.OPENJEV_API_KEY}`, "Content-Type": "application/json" }, body: JSON.stringify({ model: "openjev", state: state, questions: { main_question: { type: question_type, instructions: question_instruction } } }) }); const result = await res.json(); return { content: [{ type: "text", text: JSON.stringify(result.answers, null, 2) }] }; }); const transport = new StdioServerTransport(); await server.connect(transport);
3

Khai báo vào Antigravity / Claude Code

Chỉ cần mở file cấu hình toàn cục của Antigravity (hoặc claude_desktop_config.json của Claude) và thêm đoạn sau:

mcp_config.json
{ "mcpServers": { "openjev": { "command": "node", "args": ["C:/my-tools/mcp-openjev/index.mjs"], "env": { "OPENJEV_API_KEY": "API_KEY_CUA_BAN_O_DAY" } } } }

✨ Xong! Khởi động lại IDE, công cụ openjev_decide sẽ sẵn sàng hoạt động ở mọi thư mục dự án của bạn!
