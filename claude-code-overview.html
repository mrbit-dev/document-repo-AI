Mục 01

Tổng Quan Về Claude Code

Claude Code là công cụ lập trình dòng lệnh (CLI - Command Line Interface) được phát triển bởi Anthropic. Được xây dựng để trở thành một "đồng đội kỹ thuật", nó biến cửa sổ terminal thông thường thành một trung tâm điều phối phần mềm tự hành.

Vận Hành Tại Terminal (Terminal-Native)

Không cần rời khỏi môi trường dòng lệnh. Claude Code tương tác trực tiếp với file system, git, terminal commands, linter và build tools.

Vòng Lặp Agentic Tự Quyết (Agent Loop)

Thay vì chỉ trả về text để bạn copy/paste, Claude Code tự đặt ra kế hoạch, thực hiện từng bước, xem kết quả đầu ra (feedback), và tự sửa lỗi nếu lệnh gặp sự cố.

Đọc Hiểu Codebase Toàn Cục

Duyệt cây thư mục, tìm kiếm mã nguồn qua ripgrep, đọc tệp có chọn lọc giúp nắm bắt kiến trúc tổng thể của cả dự án lớn hàng triệu dòng code mà không tràn context.

Mục 02

Tại Sao Claude Code Lại Xuất Sắc Cho Lập Trình?

Khác biệt căn bản giữa một Chatbot thông thường và Claude Code nằm ở tính thực chiến và khả năng tự sửa sai trong môi trường runtime thật.

01

Mô Hình Tư Duy Đỉnh Cao (Claude 3.7 Sonnet)

Tích hợp khả năng Hybrid Extended Thinking (suy nghĩ kéo dài trước khi hành động). Claude Code cân nhắc các edge-case, phân tích dependency trước khi bắt tay viết code, giảm thiểu tối đa bug hồi quy (regression bugs).

02

Cơ Chế "Self-Healing" (Tự Chẩn Đoán & Sửa Lỗi)

Khi sửa code, nó tự chạy test suite hoặc linter. Nếu có lỗi biên dịch hoặc test failed, Claude Code tự đọc stack trace, quay lại file nguồn để sửa và chạy lại test cho đến khi toàn bộ passed.

03

Giữ Nhà Phát Triển Trong Trạng Thái "Flow"

Không phải alt-tab sang browser để copy code, không phải giải thích cấu trúc thư mục từ đầu. Bạn chỉ cần gõ prompt ngắn gọn bằng tiếng Anh hoặc tiếng Việt ngay tại terminal của project.

04

Git Workflows & An Toàn Mã Nguồn

Tự động kiểm tra git status, tạo branch mới, commit với message chuẩn Conventional Commits, giải quyết conflict và tạo Pull Request mà không phá hỏng git tree.

05

Cơ Chế Phân Quyền Bảo Mật (Permission Guardrails)

Mỗi thao tác nguy hiểm (chạy script lạ, rm file, push git) đều yêu cầu người dùng xác nhận hoặc tuân thủ danh sách allowlist được định nghĩa trong file cấu hình, đảm bảo tính bảo mật cho doanh nghiệp.

06

Tối Ưu Hóa Ngữ Cảnh Bằng File Slice

Thay vì đọc cả file 5000 dòng, công cụ chỉ đọc các hàm/block liên quan (slice read) và chỉnh sửa bằng chuỗi thay thế chính xác (pattern replacement), giúp tiết kiệm đáng kể chi phí token.

Mục 03

Kiến Trúc & Công Nghệ Của Claude Code

Claude Code được xây dựng trên một ngăn xếp công nghệ tinh gọn, tốc độ cao và mở rộng theo chuẩn công nghiệp:

TypeScript & Node.js

Toàn bộ CLI được viết bằng TypeScript/Node.js, đóng gói qua NPM. Tương thích đa nền tảng (macOS, Linux, Windows qua WSL/PowerShell).

LLM Claude 3.7 / 3.5 Sonnet

Hỗ trợ Function Calling & Structured Tool Outputs với độ chính xác cao nhất thế giới trong các bài benchmark SWE-bench Verified.

Model Context Protocol (MCP)

Tích hợp chuẩn giao thức MCP của Anthropic, cho phép gắn thêm các Server mở rộng (PostgreSQL, GitHub API, Jira, Local docs) như công cụ mở rộng.

Ripgrep & Fast AST Search

Sử dụng các công cụ indexing tốc độ cao như ripgrep, glob, git tree để định vị chính xác vị trí lỗi chỉ trong vài mili-giây.

Quy Trình Hoạt Động (Agentic Execution Loop):

1. User Prompt Yêu cầu từ lập trình viên
➔
2. Reasoning & Plan Suy luận & vạch chiến lược
➔
3. Tool Invocations Grep, Read, Edit, Bash
➔
4. Feedback & Test Kiểm thử & Tự sửa nếu fail

🔥 Thế mạnh của Claude Code

Khả năng giải quyết vấn đề kỹ thuật phức tạp (SWE-bench top tier), tư duy lập luận logic cực chuẩn, không làm ô nhiễm code, tuân thủ chặt chẽ styleguide hiện tại của dự án.

⚡ Thế mạnh của Codex / Copilot

Độ trễ (latency) siêu thấp khi gõ phím, tự động hoàn thành dòng code tiếp theo mượt mà, tích hợp sẵn sâu vào kho repo trên GitHub và hệ thống CI/CD Actions.

🚀 Thế mạnh của Antigravity

Kiến trúc Swarm đa tác tử (nhiều AI cùng làm việc song song), cửa sổ ngữ cảnh khổng lồ triệu tokens, tạo Artifacts trực quan và tích hợp cả trình duyệt thật để kiểm thử trực tiếp.

Mục 05

Hướng Dẫn Cài Đặt Claude Code

Yêu cầu tiên quyết: Node.js phiên bản 18+ (khuyên dùng Node 20 hoặc 22) và công cụ Git đã cài sẵn trên máy.

1 Cài đặt Global qua NPM hoặc Npx Terminal / PowerShell
npm install -g @anthropic-ai/claude-code

Hoặc nếu bạn muốn chạy ngay mà không cần cài global: npx @anthropic-ai/claude-code

2 Điều hướng đến thư mục dự án của bạn Workspace directory
cd path/to/your/project && claude
3 Xác thực tài khoản (Authentication) Anthropic Console / API Key

Trong lần chạy đầu tiên, Claude Code sẽ tự động mở trình duyệt để bạn đăng nhập qua tài khoản Anthropic Console hoặc bạn có thể thiết lập biến môi trường API Key:

# macOS / Linux (Bash/Zsh): export ANTHROPIC_API_KEY="sk-ant-..."
# Windows (PowerShell): $env:ANTHROPIC_API_KEY="sk-ant-..."
Mục 06

Cấu Hình settings.json & Nhà Cung Cấp AI Thứ 3

Claude Code lưu trữ cấu hình linh hoạt. Bạn có thể định cấu hình model, giới hạn token, ngân sách tư duy (thinking budget), cũng như trỏ tới các nhà cung cấp bên thứ ba (OpenRouter, AWS Bedrock, Google Cloud Vertex, hoặc Proxy LiteLLM/Ollama).

🌐 Cấu hình Toàn Cục (Global Settings):

Áp dụng cho mọi dự án trên máy tính của bạn:

  • • Linux/macOS: ~/.claude/settings.json hoặc ~/.claude.json
  • • Windows: %USERPROFILE%\.claude\settings.json
📁 Cấu hình Theo Dự Án (Project Settings):

Đặt trực tiếp trong thư mục gốc của repository:

  • • File dự án: ./.claude/settings.json hoặc ./.claude.json
  • • File quy chuẩn prompt: ./CLAUDE.md

Quy Ước File CLAUDE.md Trong Dự Án

Giống như file README.md dành cho con người, CLAUDE.md là tệp quy chuẩn hướng dẫn dành riêng cho Claude Code ngay khi nó bước vào repository. Hãy đặt file này ở thư mục gốc:

// Ví dụ tệp ./CLAUDE.md
# Dự Án E-Commerce Backend (NestJS + PostgreSQL)

## Lệnh Thường Dùng:
- Khởi động dev: `npm run start:dev`
- Chạy test unit: `npm run test`
- Chạy test e2e: `npm run test:e2e`
- Format & Lint: `npm run lint`

## Nguyên Tắc Code:
- Luôn sử dụng TypeScript Strict Mode.
- Mọi service mới phải có file spec tương ứng.
- Không sửa trực tiếp migration đã chạy, luôn tạo migration mới qua TypeORM.
- Sử dụng Conventional Commits cho git (feat:, fix:, chore:, refactor:).
