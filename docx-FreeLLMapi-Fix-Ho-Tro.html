Bản Fix Hỗ Trợ — Khắc phục lỗi systemd không thể khởi động service

Nguyên nhân: systemd đang yêu cầu file /home/freellmapi/freellmapi/.env nhưng file này chưa tồn tại.

Bản fix dưới đây tạo lại .env, sinh ENCRYPTION_KEY, thiết lập quyền, build lại ứng dụng và restart systemd.

1. Tạo .env

Chuyển vào thư mục FreeLLMAPI:

cd /home/freellmapi/freellmapi

Tạo file:

cp .env.example .env

Kiểm tra:

ls -la .env

2. Tạo ENCRYPTION_KEY

Chạy:

echo "ENCRYPTION_KEY=$(node -e "console.log(require('crypto').randomBytes(32).toString('hex'))")" >> .env

Kiểm tra:

grep -E '^(PORT|NODE_ENV|ENCRYPTION_KEY)=' .env

Anh sẽ thấy đại loại:

PORT=3001
ENCRYPTION_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Không gửi giá trị thật của ENCRYPTION_KEY. Khóa này dùng để mã hóa dữ liệu nhạy cảm như provider API key.
Sau khi đã có dữ liệu, không tự ý tạo ENCRYPTION_KEY mới vì dữ liệu đã mã hóa bằng khóa cũ có thể không giải mã được.

3. Kiểm tra quyền file

chown freellmapi:freellmapi /home/freellmapi/freellmapi/.env
chmod 600 /home/freellmapi/freellmapi/.env

4. Build lại một lần

cd /home/freellmapi/freellmapi
npm run build
Nếu build thành công và không có error, tiếp tục bước systemd.

5. Reload systemd

sudo systemctl daemon-reload

Sau đó:

sudo systemctl restart freellmapi

6. Kiểm tra

sudo systemctl status freellmapi --no-pager -l

Mục tiêu:

Active: active (running)
Thành công: service hiển thị Active: active (running).

7. Nếu vẫn lỗi

sudo journalctl -u freellmapi -n 100 --no-pager

Xem log realtime:

sudo journalctl -u freellmapi -f

Kiểm tra service:

sudo systemctl cat freellmapi
Khi gửi log để hỗ trợ, hãy che API key, password và ENCRYPTION_KEY.

8. Checklist sau khi fix

  1. .env tồn tại đúng đường dẫn.
  2. ENCRYPTION_KEY đã được tạo.
  3. File thuộc user freellmapi.
  4. Quyền file là 600.
  5. npm run build thành công.
  6. systemd đã reload.
  7. freellmapi.service ở trạng thái active (running).
