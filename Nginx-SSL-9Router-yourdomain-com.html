9Router → Nginx Reverse Proxy → Let's Encrypt SSL

Hướng dẫn Nginx + SSL cho 9Router

Cấu hình domain yourdomain.com truy cập 9Router đang chạy HTTPS trên port 20128 của VPS Ubuntu.

Ubuntu Nginx Let's Encrypt 9Router :20128 Domain: yourdomain.com

1. Mô hình hoạt động

Internet │ │ https://yourdomain.com ▼ ┌─────────────────────────────┐ │ VPS Ubuntu │ │ │ │ Nginx :443 │ │ │ │ │ └── reverse proxy ─────► │ 9Router :20128 │ │ └─────────────────────────────┘
Nguyên tắc: Không cần public port 20128. Chỉ public port 80 và 443. Nginx nhận HTTPS rồi chuyển tiếp request vào 9Router.

2. Kiểm tra 9Router

SSH vào VPS:

ssh root@IP_VPS

Kiểm tra port 20128:

sudo ss -tulpn | grep 20128

Vì 9Router đang chạy HTTPS, kiểm tra:

curl -k -I https://127.0.0.1:20128

Nếu thấy HTTP/1.1 200 OK, 302 hoặc response HTTP hợp lệ thì backend đang hoạt động.

3. Kiểm tra DNS

Domain phải trỏ về IP public của VPS.

dig +short yourdomain.com
curl -4 ifconfig.me
Quan trọng: Hai lệnh trên phải trả về cùng IP public của VPS. Nếu khác nhau, hãy sửa bản ghi DNS trước khi chạy Certbot.

DNS cần có dạng:

A    yourdomain.com    IP_PUBLIC_CUA_VPS

4. Cài Nginx

sudo apt update
sudo apt install nginx -y
sudo systemctl enable --now nginx
sudo systemctl status nginx

Kiểm tra Nginx:

sudo ss -tulpn | grep -E ':80|:443'

5. Mở firewall

Nếu VPS dùng UFW:

sudo ufw status

sudo ufw allow OpenSSH
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

sudo ufw status
Không cần mở port 20128 ra Internet. Nên để 9Router chỉ phục vụ phía sau Nginx.

6. Tạo cấu hình Nginx Reverse Proxy

Tạo file:

sudo nano /etc/nginx/sites-available/yourdomain.com

Dán toàn bộ cấu hình sau:

server {
    listen 80;
    listen [::]:80;

    server_name yourdomain.com;

    location / {
        proxy_pass https://127.0.0.1:20128;

        proxy_http_version 1.1;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        proxy_ssl_verify off;
    }
}

Lưu file trong nano:

CTRL + O
ENTER
CTRL + X
Vì 9Router đang chạy HTTPS: cấu hình phải dùng proxy_pass https://127.0.0.1:20128;. Nếu 9Router thực tế chạy HTTP thì đổi thành proxy_pass http://127.0.0.1:20128;.

7. Enable website

sudo ln -s /etc/nginx/sites-available/yourdomain.com /etc/nginx/sites-enabled/yourdomain.com

sudo rm -f /etc/nginx/sites-enabled/default

sudo nginx -t
sudo systemctl reload nginx

Kết quả của nginx -t phải là:

syntax is ok
test is successful

8. Test HTTP trước khi cấp SSL

curl -I http://yourdomain.com

Hoặc:

curl -v http://yourdomain.com

Nếu Nginx proxy đúng, request sẽ được chuyển vào 9Router.

9. Cài Certbot

sudo apt install snapd -y
sudo snap install snapd
sudo snap refresh snapd

sudo snap install --classic certbot

sudo ln -s /snap/bin/certbot /usr/local/bin/certbot

certbot --version

10. Cấp SSL Let's Encrypt

sudo certbot --nginx -d yourdomain.com

Certbot sẽ hỏi email và điều khoản sử dụng. Khi được hỏi có redirect HTTP sang HTTPS hay không, nên chọn:

2

Certbot sẽ tự chỉnh cấu hình Nginx để sử dụng certificate.

11. Kiểm tra Nginx và HTTPS

sudo nginx -t
sudo systemctl reload nginx

sudo ss -tulpn | grep -E ':80|:443'

Sau đó mở:

https://yourdomain.com
Luồng hoàn chỉnh:
https://yourdomain.com → Nginx :443 → HTTPS proxy → https://127.0.0.1:20128 → 9Router

12. Kiểm tra certificate

sudo certbot certificates

Phải thấy certificate cho:

Certificate Name: yourdomain.com
Domains: yourdomain.com

13. Kiểm tra tự động gia hạn SSL

sudo certbot renew --dry-run

Nếu thành công, Certbot đã có thể mô phỏng quá trình renewal.

14. Các lệnh kiểm tra nhanh khi bị lỗi

Kiểm tra 9Router

sudo ss -tulpn | grep 20128
curl -k -I https://127.0.0.1:20128

Kiểm tra Nginx

sudo nginx -t
sudo systemctl status nginx
sudo journalctl -u nginx -n 100 --no-pager

Xem log access/error

sudo tail -f /var/log/nginx/access.log
sudo tail -f /var/log/nginx/error.log

Kiểm tra DNS

dig +short yourdomain.com
curl -4 ifconfig.me

Kiểm tra firewall

sudo ufw status verbose

15. Nếu Certbot báo lỗi

Lỗi thường gặp: domain chưa trỏ đúng IP, port 80 bị firewall chặn, firewall của nhà cung cấp VPS chặn port 80/443, hoặc DNS chưa cập nhật.

Kiểm tra:

dig +short yourdomain.com
curl -4 ifconfig.me

sudo ufw status verbose

sudo ss -tulpn | grep -E ':80|:443|:20128'

Nếu VPS có Security Group / Cloud Firewall riêng của nhà cung cấp, cũng phải mở:

TCP 80
TCP 443

16. Bảo mật khuyến nghị

  • ✓ Public port 80 và 443.
  • ✓ Không public port 20128 nếu không cần.
  • ✓ 9Router nên bind localhost nếu có thể.
  • ✓ Sử dụng HTTPS cho domain.
  • ✓ Giữ Ubuntu, Nginx và 9Router cập nhật.
  • ✓ Dùng mật khẩu mạnh cho giao diện 9Router.

17. Bộ lệnh đầy đủ để làm từ đầu

Chỉ chạy phần này sau khi DNS yourdomain.com đã trỏ đúng IP public của VPS và 9Router đang chạy HTTPS trên port 20128.

sudo apt update
sudo apt install nginx snapd -y

sudo systemctl enable --now nginx

sudo ufw allow OpenSSH
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

sudo nano /etc/nginx/sites-available/yourdomain.com

sudo ln -s /etc/nginx/sites-available/yourdomain.com /etc/nginx/sites-enabled/yourdomain.com
sudo rm -f /etc/nginx/sites-enabled/default

sudo nginx -t
sudo systemctl reload nginx

sudo snap install snapd
sudo snap refresh snapd
sudo snap install --classic certbot

sudo ln -s /snap/bin/certbot /usr/local/bin/certbot

sudo certbot --nginx -d yourdomain.com

sudo nginx -t
sudo systemctl reload nginx

sudo certbot certificates
sudo certbot renew --dry-run

Người dùng │ │ https://yourdomain.com ▼ Internet / DNS │ ▼ VPS Ubuntu │ ▼ Nginx :443 │ │ Reverse Proxy ▼ 9Router HTTPS :20128
URL cuối cùng:
https://yourdomain.com
